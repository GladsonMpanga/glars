GLARS PRIVATE SECONDARY SCHOOL WEBSITE

FILES
- index.html       Home page
- about.html       About the school
- academics.html   Academic information
- admissions.html  Admissions overview
- contact.html     Contact details and demo enquiry form
- styles.css       Shared responsive styling
- script.js        Mobile navigation, year and demo contact form
- assets/glars-logo.jpg  Uploaded school logo

HOW TO VIEW
1. Extract the ZIP folder.
2. Open index.html in a modern browser. No build step is required.

BEFORE PUBLISHING
- Replace the image placeholders with approved school photographs.
- Replace placeholder contact details and school-specific information.
- Confirm the official subjects, admissions requirements, fees, address and policies.
- In script.js, replace school@example.com with the official school email.
- The contact form currently opens the visitor's email application; it does not store messages.
- Google Fonts load online. The page still uses fallback fonts if unavailable.

All pages share styles.css and script.js. Keep the folder structure unchanged so links and the logo continue to work.
